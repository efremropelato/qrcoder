```bash
wails build

# Go only (no frontend)

```

## Architecture

Desktop app built with **Wails v2** — Go backend exposed to a React/TypeScript frontend via auto-generated JS bindings.

### Go backend (`app.go`)
Single `App` struct bound to the Wails runtime. Three exported methods:
- `GenerateQRCode(QRParams) (string, error)` — builds QR image, returns base64-encoded PNG for preview
- `SaveQRCode(QRParams) (string, error)` — opens a native save dialog, writes PNG to disk
- `SelectLogoFile() (string, error)` — opens a native open dialog filtered to images

`QRParams` carries `url`, `size`, `fgColor`, `bgColor`, `logoPath`. Generation always uses error-correction level **H** (required when a logo overlays ~25% of the center). Logo compositing uses `golang.org/x/image/draw` (Catmull-Rom scaling) + stdlib `image/draw`.

### React frontend (`frontend/src/App.tsx`)
Single page, two-column layout (sidebar form + preview pane). Calls Go methods via bindings auto-generated by Wails at `frontend/wailsjs/go/main/App.js` — regenerated on every `wails dev` run; do not edit manually.

### Wails binding flow
`wails dev` → generates `frontend/wailsjs/` → compiles Go with CGO (Cocoa/WebKit) → launches native macOS window pointing at the Vite dev server (port 5173). The Wails IPC layer is injected at port 34115.
